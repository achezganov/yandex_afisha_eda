# Анализ лояльности пользователей Яндекс Афиши
## Описание проекта
В проекте выполнен исследовательский анализ данных сервиса **Яндекс Афиша** с фокусом на лояльность пользователей и повторные покупки. Основная цель — понять, какие характеристики первого заказа и дальнейшего поведения связаны с возвратом пользователя на платформу.

Проект оформлен в виде ноутбука `main.ipynb`, где последовательно показаны постановка задачи, описание данных, предобработка, исследовательский анализ и выводы. В репозитории также есть SQL-витрина, на основе которой формируется датасет для анализа.

## Цель проекта
Провести исследовательский анализ данных и определить факторы, влияющие на повторные заказы пользователей Яндекс Афиши.

## Задачи проекта
- изучить структуру исходных данных;
- подготовить SQL-запрос для выгрузки аналитической витрины;
- выполнить предобработку данных;
- сформировать пользовательский профиль;
- исследовать поведение пользователей и повторные заказы;
- оценить связи между признаками;
- сформулировать выводы и рекомендации.

## Что анализируется
В анализе используются данные о:
- пользователях;
- заказах и времени покупки;
- типе устройства;
- выручке;
- количестве билетов;
- типе мероприятия;
- билетном операторе;
- регионе и городе;
- интервале между покупками.

В проекте рассматриваются, в частности, такие поля:
- `user_id`
- `device_type_canonical`
- `order_id`
- `order_dt`
- `order_ts`
- `currency_code`
- `revenue`
- `tickets_count`
- `days_since_prev`
- `event_id`
- `service_name`
- `event_type_main`
- `region_name`
- `city_name`

## SQL-часть проекта
Файл `sql/marts/afisha_purchases_mart.sql` используется для подготовки витрины данных под дальнейший анализ.

По содержанию проекта SQL-логика решает две основные задачи:
- собирает в одну таблицу данные по заказам, пользователям и событиям;
- подготавливает признаки для анализа повторных покупок, включая интервал с предыдущим заказом.

## Основные этапы анализа в `main.ipynb`
### 1. Постановка задачи
В ноутбуке сформулирована цель: понять, какие пользователи с большей вероятностью возвращаются на платформу и совершают повторные заказы.

### 2. Знакомство с данными
Ноутбук содержит описание состава датасета и базовый обзор признаков.

### 3. Предобработка
На этом этапе выполняются:

- проверка структуры данных;
- анализ распределений;
- подготовка признаков для пользовательского уровня;
- очистка данных перед EDA.

### 4. Формирование пользовательского профиля
Для каждого пользователя рассчитываются агрегированные метрики, связанные с:

- первым заказом;
- количеством заказов;
- средней выручкой;
- средним числом билетов;
- средним интервалом между заказами.

### 5. Исследовательский анализ
В ноутбуке исследуются:

- тип первого мероприятия;
- среднее количество билетов;
- средняя выручка;
- различия между вернувшимися и невернувшимися пользователями;
- распределение повторных покупок по сегментам.

### 6. Корреляционный анализ
Для оценки связи между признаками используется в том числе коэффициент `phik`.

### 7. Выводы
Проект завершается интерпретацией результатов и рекомендациями по работе с удержанием пользователей.

## Как запустить проект

### 1. Клонировать репозиторий

```bash
git clone https://github.com/achezganov/yandex_afisha_eda.git
cd yandex_afisha_eda
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv
source .venv/bin/activate
```

Для Windows:

```bash
.venv\Scripts\activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Открыть ноутбук

```bash
jupyter lab
```

После запуска откройте `main.ipynb`.
